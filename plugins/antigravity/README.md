# ProjectMind for Google Antigravity

Universal local-first project intelligence, persistent context engine, and autonomous lifecycle hooks for Google Antigravity.

## Supported Capabilities
- **MCP Transport**: `stdio`
- **Native Plugin**: `true`
- **MCP Server**: `true`
- **Agent Skills**: `true`
- **Lifecycle Hooks**: `true`
- **Instruction File**: `true`
- **Automatic Invocation**: `hooks_and_skills`
- **Reload Mechanism**: `hot_reload`

## Quick Start
```bash
# Install integration for this agent
projectmind plugin install antigravity

# Verify configuration and health
projectmind plugin verify antigravity

# Cleanly remove integration
projectmind plugin uninstall antigravity
```
