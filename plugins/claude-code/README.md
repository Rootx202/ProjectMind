# ProjectMind for Anthropic Claude Code

Universal local-first project intelligence, MCP server, skills, and settings hooks for Anthropic Claude Code.

## Supported Capabilities
- **MCP Transport**: `stdio`
- **Native Plugin**: `true`
- **MCP Server**: `true`
- **Agent Skills**: `true`
- **Lifecycle Hooks**: `true`
- **Instruction File**: `true`
- **Automatic Invocation**: `hooks_and_skills`
- **Reload Mechanism**: `restart_required`

## Quick Start
```bash
# Install integration for this agent
projectmind plugin install claude-code

# Verify configuration and health
projectmind plugin verify claude-code

# Cleanly remove integration
projectmind plugin uninstall claude-code
```
