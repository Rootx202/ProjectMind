# ProjectMind for Hermes Agent (Nous Research)

Autonomous project intelligence, Native MCP client integration, HERMES.md instruction file, and self-improving memory loop.

## Supported Capabilities
- **MCP Transport**: `stdio`
- **Native Plugin**: `true`
- **MCP Server**: `true`
- **Agent Skills**: `true`
- **Lifecycle Hooks**: `true`
- **Instruction File**: `true`
- **Automatic Invocation**: `hooks_and_skills`
- **Reload Mechanism**: `hot_reload`

## Quick Start
```bash
# Install integration for this agent
projectmind plugin install hermes-agent

# Verify configuration and health
projectmind plugin verify hermes-agent

# Cleanly remove integration
projectmind plugin uninstall hermes-agent
```
