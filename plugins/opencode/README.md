# ProjectMind for OpenCode (anomalyco / opencode.ai)

Universal local-first project intelligence, opencode.json local MCP server, and AGENTS.md rules for OpenCode.

## Supported Capabilities
- **MCP Transport**: `stdio`
- **Native Plugin**: `false`
- **MCP Server**: `true`
- **Agent Skills**: `true`
- **Lifecycle Hooks**: `true`
- **Instruction File**: `true`
- **Automatic Invocation**: `mcp_instructions_and_skills`
- **Reload Mechanism**: `hot_reload`

## Quick Start
```bash
# Install integration for this agent
projectmind plugin install opencode

# Verify configuration and health
projectmind plugin verify opencode

# Cleanly remove integration
projectmind plugin uninstall opencode
```
